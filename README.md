Este repositorio se ha creado para darle seguimiento a todos los aspectos relacionados a la Planta de tratamiento de Kenzo Jeans. En un esfuerzo encaminado a disminuir el consumo de papel, a generar procesos que puedan llegar a ser más eficientes y que sean más prácticos para el operario de la Planta, se llega al desarrollo de este dashboard para el control de Parámetros en vertimientos de Tintorería, agua tratada, mantenimiento y el consumo de químicos (kardex). El seguimiento de la base de datos que alimenta este dashboard se encuentra en la hoja de cálculo del drive de Gestión Ambiental, llamada "REGISTRO DE PARÁMETROS - VERTIMIENTOS TINTORERÍA" (url: https://docs.google.com/spreadsheets/d/12iJMb1ujmfzng1NQ7o4iD2COwvkMvxwOrU7s92UT4Ek/edit?gid=248312250#gid=248312250), cabe resaltar que la información se diligencia desde el form de google que se encuentra también creado desde el perfil de Gestión Ambiental (url: https://docs.google.com/forms/d/1nkyjquyjixniyzQY3t-Igd6hsrge1fnDb9Eiie8McKQ/edit), úsese este formulario cada vez que se debe reportar un mantenimiento, (url: https://docs.google.com/forms/d/13DZPnW9612dWDk2xzrCBIisMhOSy5B-Cfms4w6I8maU/edit) este para el reporte de parámetros en vertimientos de tintorería,( url: https://docs.google.com/forms/d/1GKhlGf1po2-xHwpBm98M7-PUi7fS_mSbzgUERrjJokI/edit) este para el reporte de los valores de agua tratada diaria y por último (url: https://docs.google.com/forms/d/1YRx2C9OyHD2eKAjjAoV_dzM-4QHESZyJVPbf5gIOlbY/edit) use este para reportar el consumo de químicos cada vez que se prepare. *Evite a toda costa reportar en días posteriores, procure que la información se diligencie una vez se midan los parámetros, se preparen los químicos o se realice el mantenimiento*.
